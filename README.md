# dweepangain

Dweepan Gain — AI Engineer | Full-Stack Developer

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fdweepangainjob-oss%2Fdweepangainjob-oss)

Deploy this repository to Vercel to create a public URL for the live portfolio. After the first deployment, share that URL so others can open the site directly.

## Requirements

- Node.js 22.6 or newer
- Corepack (included with supported Node.js releases)

The repository uses pnpm 12.3.4 through Corepack and keeps dependency resolution in `pnpm-lock.yaml`.

## Run locally

```powershell
corepack pnpm install
corepack pnpm dev
```

Or double-click `run-portfolio.bat` on Windows. The app is served at `http://localhost:3001`. The dev server also prints a Network URL for access from other devices on your LAN.

## Deploy

Use the Deploy with Vercel button above and follow Vercel's prompts to import this GitHub repository. Vercel detects Next.js and builds the app. The generated deployment URL is the live link to share.

## Validate

```powershell
corepack pnpm test
corepack pnpm exec playwright install chromium
corepack pnpm test:e2e
corepack pnpm build
```

The end-to-end tests use `http://localhost:3001`, reusing the local server when it is already running.

## Deployment metadata

Set `NEXT_PUBLIC_SITE_URL` to the public origin of the deployed site. Vercel deployments use `VERCEL_URL` automatically when the explicit variable is absent. The Open Graph and Twitter share image is generated by `app/opengraph-image.tsx`.

## Portfolio content

Edit `lib/portfolio-config.ts` for profile details, projects, skills, and any available project demo URLs. The terminal's AI engineer and full-stack modes focus the project and skill sections; the printable resume continues to show the complete portfolio.

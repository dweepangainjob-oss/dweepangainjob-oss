# dweepangain

Dweepan Gain — AI Engineer | Full-Stack Developer

[![GitHub Pages deployment](https://github.com/dweepangainjob-oss/dweepangainjob-oss/actions/workflows/deploy.yml/badge.svg)](https://github.com/dweepangainjob-oss/dweepangainjob-oss/actions/workflows/deploy.yml)

[Open the live portfolio](https://dweepangainjob-oss.github.io/dweepangainjob-oss/)

## Requirements

- Node.js 22.6 or newer
- Corepack (included with supported Node.js releases)

The repository uses pnpm 12.3.4 through Corepack and keeps dependency resolution in `pnpm-lock.yaml`.

## Run locally

```powershell
corepack pnpm install
corepack pnpm dev
```

Or double-click `run-portfolio.bat` on Windows. The app is served at `http://localhost:3001`. The dev server also prints a Network URL for access from other devices on your LAN.

## Deploy

GitHub Actions builds and publishes the site to GitHub Pages whenever changes are pushed to `main`. The public site is available at [dweepangainjob-oss.github.io/dweepangainjob-oss](https://dweepangainjob-oss.github.io/dweepangainjob-oss/). The first deployment may take a few minutes.

## Validate

```powershell
corepack pnpm test
corepack pnpm exec playwright install chromium
corepack pnpm test:e2e
corepack pnpm build
```

The end-to-end tests use `http://localhost:3001`, reusing the local server when it is already running.

## Deployment metadata

The GitHub Pages workflow configures `NEXT_PUBLIC_SITE_URL` and the repository base path at build time. The Open Graph and Twitter share image is generated by `app/opengraph-image.tsx`.

## Portfolio content

Edit `lib/portfolio-config.ts` for profile details, projects, skills, and any available project demo URLs. The terminal's AI engineer and full-stack modes focus the project and skill sections; the printable resume continues to show the complete portfolio.
